    The full model is too large to run in a browser, so this page uses a smaller Random Forest trained the same way. Risk bands: Low below 30%, Medium 30–60%, High 60% and above. Learning project on the public Kaggle "Bank Customer Churn Dataset"; not for real customer decisions.
